# Snake Gun Water Game

This is a simple Java console game where the user plays Snake-Gun-Water against the computer.

## How to Run

1. Copy the code from `practice.java`.
2. Paste it into any Java IDE (like VS Code, IntelliJ, or BlueJ).
3. Compile and run the file.

## Game Rules

- Snake beats Water
- Gun beats Snake
- Water beats Gun

Enjoy the game!
